# Nym Desktop

Downloads for the Nym desktop app.

**[Download for your platform](https://metonymousai.github.io/nym-desktop-releases/)**

Or take a direct link. These always point at the newest version:

| | |
| --- | --- |
| macOS (Apple silicon) | [Nym-macOS-arm64.dmg](https://github.com/MetonymousAI/nym-desktop-releases/releases/latest/download/Nym-macOS-arm64.dmg) |
| macOS (Intel) | [Nym-macOS-x64.dmg](https://github.com/MetonymousAI/nym-desktop-releases/releases/latest/download/Nym-macOS-x64.dmg) |
| Windows | [Nym-Windows-x64-Setup.exe](https://github.com/MetonymousAI/nym-desktop-releases/releases/latest/download/Nym-Windows-x64-Setup.exe) |
| Linux (AppImage) | [Nym-Linux-x86_64.AppImage](https://github.com/MetonymousAI/nym-desktop-releases/releases/latest/download/Nym-Linux-x86_64.AppImage) |
| Linux (Debian, Ubuntu) | [Nym-Linux-amd64.deb](https://github.com/MetonymousAI/nym-desktop-releases/releases/latest/download/Nym-Linux-amd64.deb) |

If you would rather have the macOS app as a plain archive, every release also
includes [Nym-macOS-arm64.zip](https://github.com/MetonymousAI/nym-desktop-releases/releases/latest/download/Nym-macOS-arm64.zip)
and [Nym-macOS-x64.zip](https://github.com/MetonymousAI/nym-desktop-releases/releases/latest/download/Nym-macOS-x64.zip).

Every release lists file sizes and SHA-256 checksums in `manifest.json`, and the
[Releases page](https://github.com/MetonymousAI/nym-desktop-releases/releases) keeps
older versions.

Nym itself lives at [usenym.com](https://usenym.com).
